Navigation & File Management:

  - pwd: Print Working Directory.
  - ls: List files.

  - python3: Run script.

  - conda activate: Switch environments.

Hardware Monitoring:

  - clear: Clean screen.

Environment & Virtualization Legend
Environment & Virtualization Legend

Environment Variables:

  - export NAME=VALUE : Set a temporary variable.
  - env : List all active environment variables.
  - echo $NAME : Show value of a specific variable.

Python venv:

  - python3 -m venv name : Create an isolated environment.
  - source name/bin/activate : Activate the environment.
  - deactivate : Exit the environment.

Conda Management:

  - conda env list : List all conda environments.
  - conda create --name name : Create new environment.
  - conda activate name : Enter specific environment.
  - conda remove --name name --all : Delete environment.

Dependencies:

  - source .env : Load variables from a file.
  - pip freeze > requirements.txt : Save current tool list.
